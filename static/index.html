PROJECT DETAIL

  
CONNECT YOUR WORK
接入一个项目，
连起网站与工作进展。
以下命令在 Workhub 项目目录运行。全局入口让 Agent 自动读取规则；项目入口为其他兼容 Agent 提供明确指引。
01
安装全局必读入口
接入 Codex、Z Code、Claude Code 的全局规则。
python3 scripts/install.py --global
02
接入具体项目
替换为真实路径；已有项目规则会保留。
python3 scripts/install.py --project /path/to/project
03
记录真实工作
Agent 按 skill 记录开工、进展、完成和阻塞。
python3 workhub.py record --project /path/to/project --agent codex --status running --summary 'Start project task'
04
把已有网站放进项目空间
接入本地 HTML 网站目录；已有运行服务也支持用 --url 接入。
python3 workhub.py site-add --project /path/to/project --name Project-site --directory /path/to/site
历史记录不会自动补写。未读取这些入口的 Agent 或远程环境，需要先接入同一套规则和记录端。
