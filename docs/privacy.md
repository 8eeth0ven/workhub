# 数据与发布边界

## 本机存储

项目路径、名称、简介、工作记录、补充回答与模型评议存储在使用者自己的状态目录，默认 `~/.local/share/agent-workhub`，可由 `AGENT_WORKHUB_HOME` 更改。该目录还可能包含数据库、规则备份、模型配置、日志、会话进程记录和可选运行副本。

学习卡的概念讲解、实现细节、源码相对路径、版本和用户理解勾选也保存在这个私有数据库中。页面读取、筛选、刷新及勾选不调用模型；由编码 Agent 整理的新卡通过本地 CLI 写入。发布源码或制作演示时，不包含用户的真实学习卡、源码片段或理解状态。

启用项目档案后，还可本地保留实际 Agent、会话来源、必要的任务提示词及显式选择的发布物快照。原始委托与重构的 `derived` 版本分开，保留来源、版本与哈希；不复制完整聊天。提示词含凭据时默认拒绝，只有显式选择脱敏才存标明为派生的副本，原始凭据不落盘。

界面语言偏好保存在当前门户来源的浏览器本地存储中，不写入项目正文，也不会为语言切换触发翻译或模型请求。项目名称、工作记录、网站内容及已有评议保留原始语言。

发布源代码不应包含这些实际运行资料。仓库中的模板演示使用合成内容，正式生成的网站默认 `is_demo=false`、`items=[]`。不要用个人数据库替换演示数据，不要把实际项目清单、截图或配置复制到示例目录。

## 何时会发送数据

默认本地门户只绑定回环地址。克隆、前台启动和技能安装不会自行调用模型。用户主动配置并启用评议时，后端向配置的 API 或 CLI 发送有限的项目名、简介、近期工作摘要、补充回答及证据标识；不自动读取完整项目仓库、聊天记录或环境文件。

后端会去除已知凭据和部分敏感字段，但自动脱敏无法保证识别所有敏感内容。登记工作摘要、回答追问或发起评议前，应确认这些内容适合交给所选模型。选择本机模型或 CLI 时，也需要了解该工具自己的联网、日志与数据保留行为。

归档的原始提示词与发布物文件不会默认送入模型评议请求。本地保留不等于外发许可；需要用作评议背景时，先选择必要且适合发送的摘要。发布物快照只沿显式入口、本地图片/CSS依赖及显式附件保留，不因指定目录就读取或公开兄弟稿件。

密钥只由后端从私有配置或环境读取，不应放进前端、工作记录、截图、Git 或命令参数。`llm.json` 与兼容的 `glm.json` 必须保持私有；示例只使用明确占位符。CLI 命令仅来自本机用户配置，网页 API 不提供命令执行参数。

## 网站可见性

门户会读取用户明确接入的静态网站目录，并为该目录提供回环地址预览。接入前应确认目录适合浏览器访问，不应把含密钥和私有配置的项目根目录作为网站根目录。服务拒绝隐藏文件和越界路径，但这不等同于了解所有业务文件的敏感程度。

已有本机服务保留自己的数据、权限和运行方式。`localhost` 表示访问者的电脑，本机地址不能天然跨机器访问。门户不提供通用代理来绕过其他网站的嵌入或浏览器保护。

## 发布检查

```sh
python3 scripts/audit_release.py
```

检查仅扫描当前发布目录的候选源文件和 Git 可能跟踪的文件，不读取用户状态目录、密钥配置或 Agent 历史。Git 仓库内以已跟踪文件与非忽略的待添加文件为候选；已跟踪但后来加入忽略规则的私有文件仍会被阻止。没有 Git 元数据时，使用受限的源文件遍历，并对敏感文件名和运行产物报错。

扫描发现个人 home 绝对路径、疑似凭据或私钥、数据库、私有配置、运行副本等候选内容时返回非零退出码。输出只给出相对文件名、类型和行号，不回显疑似密钥。它是发布前的启发式检查，不能替代对实际变更、示例和截图的人工复核。

`.gitignore` 排除环境配置、模型私有配置、数据库、日志、运行目录、导出、报告和截图；只有经检查的文档截图可放在 `docs/images/`。普通 `git add` 不应带入这些运行文件，但已跟踪文件不会因新增忽略规则自动消失，应在发布前检查暂存内容。
