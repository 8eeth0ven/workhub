# 发布检查摘要

本仓库是独立源代码发布目录，不包含实际用户的工作数据库、模型密钥、Agent 全局配置或项目工作历史。

已完成的检查：

- 安装器在临时 home 中验证原规则保留、精确备份、权限保留、同名冲突预检与重复执行幂等。
- 模板生成及统一设计规范通过回归；正式网站默认无演示条目。
- 可选 launchd 运行副本包含后端、评议模块、静态资源和模板；默认独立会话模式不触发全局安装。
- 发布扫描拒绝个人 home 路径、真实格式的提供者令牌、私钥、私有配置和运行产物；只输出相对文件名、类型和行号，不输出匹配值。
- 扫描回归确认明确占位符和公钥可通过，测试目录中的真实格式令牌仍被阻止，已跟踪但后来被忽略的私有文件仍被阻止。
- 发布流程全量测试通过；安装及发布扫描回归 18 项、统一设计回归 3 项通过。技能元数据校验通过。

复核命令：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/audit_release.py
git diff --check
```

检查仅覆盖当前发布源文件与 Git 候选文件；不读取使用者的私有状态目录。文档图片需单独进行内容复核，扫描工具不解析图片像素。启发式扫描零发现不等于对任意未来改动的安全保证，发布前应重新运行检查并审阅暂存内容。
